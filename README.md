🐾 Pet Life Manager
A premium, interactive virtual pet management application built with modern web technologies. Experience the joy of raising your own digital companion with real-time state management and a beautiful, responsive interface.

✨ Features
Dynamic Pet Interaction: Engage with your pet through various activities to maintain its well-being.
Real-time Vital Tracking: Sophisticated monitoring system for Hunger, Happiness, and Cleanliness.
Interactive Action Suite:
🍖 Alimentar (Feed): Nutritious meals to keep your pet healthy.
🧶 Brincar (Play): Stimulating activities for emotional balance.
🚿 Banho (Bath): Essential grooming for peak hygiene.
Integrated Marketplace: A dedicated store system for items and upgrades.
Legacy Journal: Document your pet's growth and milestones.
Premium UI/UX: Crafted with Tailwind CSS and Radix UI for a seamless experience across all devices.
🛠️ Technology Stack
Core: TanStack Start (Full-stack React Framework)
Library: React 19
Build Engine: Vite
Design System: Tailwind CSS
Components: Radix UI
State Management: TanStack Query
Navigation: TanStack Router
Iconography: Lucide React
📦 Quick Start
Prerequisites
Node.js (v18 or higher)
npm or Bun
Installation & Execution
Clone & Enter:

git clone https://github.com/luanhayalla2/pet-life-manager.git
cd pet-life-manager
Install Dependencies:

npm install
Launch Application:

npm run dev
Access: Open http://localhost:8080 to meet your new friend.

📂 Architecture
src/components: Premium UI modules and game-specific displays.
src/hooks: Encapsulated game logic and state synchronization.
src/routes: High-performance routing architecture.
src/lib: Core utilities and global configurations.
src/styles.css: Advanced styling and design tokens.
